# TetherLRS firmware

The firmware of TetherLRS. It starts from [mLRS](https://github.com/olliw42/mLRS) by OlliW and the mLRS contributors,
at mLRS commit `1eca7374` (v1.4.05 dev), kept here as a git subtree; what TetherLRS changed is in this repository's
history. The [mLRS documentation](https://github.com/olliw42/mLRS-docu) describes the link and most settings; its
parts on RC channels, radio bays, EdgeTX and Lua scripts do not apply to TetherLRS.

See the [README](../README.md) at the top for what TetherLRS is, how to build it, and the disclaimer.
